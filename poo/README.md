# Programacion Orientada a Objetos — Analogias Biologicas

Aprendizaje de POO usando senalizacion celular y hormonas como modelo.
Cada etapa introduce un concepto nuevo, con ejercicios que construyen
sobre los anteriores.

## Estructura

| Carpeta | Concepto | Analogia biologica |
|---|---|---|
| `00_etapa_procedural/` | Por que se necesita POO | Funciones sueltas que no saben a quien se aplican |
| `01_clases_y_metodos/` | Clase, objeto, `self`, metodos | Gen → molecula en plasma |
| `02_encapsulacion/` | `@property`, validacion, atributos privados | Membrana con canales regulados |
| `03_herencia/` | Clase base, `super()`, jerarquias | Taxonomia: LinfocitoT es un Leucocito |
| `04_polimorfismo/` | Misma interfaz, distinta respuesta | Acetilcolina en musculo vs nodo SA |
| `05_solid/` | Principios SOLID | Senalizacion paracrina |

## Tabla de analogias

| Programacion | Biologia |
|---|---|
| Clase | Gen (la instruccion, el molde) |
| Objeto / Instancia | Molecula concreta en plasma |
| Atributo | Propiedad medible (concentracion, estado) |
| Metodo | Capacidad que la molecula lleva consigo |
| `self` | "Esta molecula especifica" |
| `__init__` | Plegamiento postraduccional |
| Encapsulacion | Membrana con canales regulados |
| Herencia | Taxonomia estatica (IS-A) |
| Polimorfismo | Mismo mensaje, distinta respuesta celular |
